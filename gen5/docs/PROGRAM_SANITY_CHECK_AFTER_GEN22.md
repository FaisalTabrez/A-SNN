# Program sanity check after Gen-22

Date: 2026-08-20

Gen-22 strengthens the project by falsifying an apparent positive result. The
program's goal is causal brain-inspired adaptation, not merely storing numbers
in variables named STW and LTW. Because the previous transfer conserved the
effective sum exactly, it did not implement functional memory separation.

Supported evidence remains residual LIF state on event audio and conventional
post-lesion adaptation. Dynamic topology, useful learned delays, reliable local
credit, functional dual timescales, replay, and hardware energy remain unproven
or rejected under their current rules.

The next phase is a single corrected dual-memory test, not a larger combined
model. Gen-23 consolidates only at the A/B boundary, protects utility-selected
LTW slots from B updates, bounds the remaining STW, and compares against both
single memory and bounded STW without consolidation. Shuffled selection tests
whether pathway identity matters. Failure closes the readout dual-memory branch;
passing only authorizes a backbone-synapse replication.
