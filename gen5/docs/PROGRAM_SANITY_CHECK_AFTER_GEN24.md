# Program sanity check after Gen-24

Gen-24 strengthens rather than redirects the project. Residual LIF state is the
only mechanism with replicated task and causal evidence, and compilation now
shows that its earlier software cost was not fundamental. This supports a
credible systems path without reviving adaptive mechanisms that failed their
registered gates.

The next phase must remain causal and matched: replace only the dense temporal
input operator with event-driven routing, reuse the identical residual-LIF
state head and weights, and require numerical equivalence before considering
speed. Real SSC and registered synthetic densities separate an actual workload
result from a sparsity crossover study. Accuracy and hardware-energy claims
remain unchanged.
