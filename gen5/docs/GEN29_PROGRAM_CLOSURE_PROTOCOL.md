# Gen-29 causal evidence closure protocol

Date frozen: 2026-08-20

Gen-29 is a deterministic synthesis phase, not a training experiment. It
hashes the authoritative analysis documents from Phase 47 through Gen-28 and
emits a claim ledger covering neural mechanisms, adaptive mechanisms, systems
execution, and hardware claims.

The phase passes only if every required evidence document exists, all claims
have an explicit supported/rejected/untested status, and the decision preserves
the established boundaries:

- residual LIF state is supported only as a cooperative, sample-specific
  event-audio mechanism;
- topology, dual-memory advantage, learned delays, and local reward credit are
  not supported under matched controls;
- compiled residual-LIF execution is supported;
- generic COO and the current Triton event kernel are closed;
- hardware-energy benefit remains untested.

Gen-29 cannot promote a mechanism, alter a metric, or authorize Gen-30. Its
output determines the requirements for a separately preregistered successor
workstream.
